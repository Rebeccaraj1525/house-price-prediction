# 🏠 House Price Prediction

My first Machine Learning project! Predicts house prices using
Linear Regression with Scikit-learn based on features like
area, bedrooms, bathrooms and amenities.

## 📌 Key Findings
- Larger area strongly correlates with higher price
- More bedrooms generally means higher price
- Air conditioning and preferred area significantly affect price
- Model achieved R² score showing good prediction accuracy

## 🤖 Machine Learning Model
- Algorithm: Linear Regression
- Library: Scikit-learn
- Train/Test Split: 80% / 20%
- Evaluation: MAE, RMSE, R² Score

## 🛠️ Tools Used
- Python 3, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
